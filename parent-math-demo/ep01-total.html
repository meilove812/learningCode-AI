分类题解题技巧

二年级上 · 分类与整理 · 第一单元

看看这6个东西

有圆有方，颜色也不一样🤔

想好按什么来分

先试试按 颜色 来分！

红色：2个

红圆 + 红方 = 2 个

蓝色：2个

蓝圆 + 蓝方 = 2 个

绿色：2个

绿圆 + 绿方 = 2 个

加起来！
2 + 2 + 2 = 6 ✅

跟总数一样，没重没漏！

换一种分法！

这次按 形状 来分

圆形：3个

红圆 + 蓝圆 + 绿圆 = 3 个

方形：3个

红方 + 蓝方 + 绿方 = 3 个

加起来！
3 + 3 = 6 ✅

换了分法，总数不变！

🌟 三步法

1️⃣ 想好按什么分

按颜色、按形状、按大小……选一个标准

2️⃣ 分一分，数一数

按标准分组，每组数清楚

3️⃣ 加一加，对总数

各组加起来等于总数，就分对了

掌握这个思路，分类题都能用！
