# Coco 学习站

一个面向儿童的静态学习站。当前从二年级上册开始，按“年级 → 学科 → 单元 → 课程”组织。

## 原则

- 只发布重新编写并完成隐私检查的内容。
- 不复制教材全文、原题、插图、歌曲或特定教材的页码式编排。
- 不声称与出版社、学校或考试机构存在官方关系。
- 运行时不采集姓名、作答记录或其他个人数据。
- 语音使用浏览器 Web Speech API；本站不保存朗读文本或作答记录。

## 本地预览

使用任意静态文件服务器从仓库根目录启动；也可直接打开 `index.html` 浏览大多数内容。

## 二年级课程

语文包含观察顺序、因果表达、认字笔顺描红和综合挑战；数学包含分类标准、统计图、多标准分类和综合挑战。课程页支持点击朗读、连续播放与打印。汉字笔顺组件和字形数据的许可见 `CONTENT-SOURCES.md`。

## 进度映射

学期进度与能力点的内部映射见 `CURRICULUM-MAP.md`。公开页面只呈现年级、学科、课程和学习功能。


## 默认发布目标

除非用户明确指定其他仓库，所有新增、改造和发布默认目标均为公开仓库 `meilove812/learningCode-AI`。旧私有仓库 `meilove812/learningCode` 仅作只读来源：不得在其中改动、提交或推送。迁移时只复制已完成版权、隐私和依赖检查的内容。

## 栏目与语音控件

- `explore/culture/`：文化主题，包括“认识中国56个民族”。
- `ai-insights/`：AI 洞察竖屏视频页与专题讲解，自包含、可离线。
- 纯导航页不显示语音工具条；课程或内容页把局部播放、语音选择和语速控件放在对应内容区域。
- Web Speech API 优先选择 Microsoft Xiaoxiao Online (Natural)（中文）或 Microsoft Ava Online (Natural)（英文），并监听 `voiceschanged`；不上传朗读文本。

## 课程设计口径

- 课程能力依据公开的新课程标准中的学段目标、核心素养、内容领域与能力要求，经摘要和重述后落实；不逐字复制大段标准文本。
- 可按年级、学期及常见单元进度安排公开导航，并用“单元 / 知识点 / 具体课次定位”帮助配套学习，但不宣称与某一教材官方同步。
- 教材按受保护内容处理：不复制现代课文、原题原图、教材讲解与答案、扫描页、音视频或独创编排。
- 公开页的内容、练习、例句、题面和图示均重新编写；课次与能力点的对应关系仅在 `CURRICULUM-MAP.md` 中维护。

## 一、二年级写字模块

一年级和二年级所有生字、写字页面统一遵循 [`WRITING-STANDARD.md`](WRITING-STANDARD.md)：每个字必须同时具备本地真实笔顺动画（逐画播放、暂停/继续、重播）、逐画描红与可打印字模/空白田字格、按实际顺序列出的笔画名称、汉字/带调拼音/语境词语，以及单卡和连续朗读。发布前运行 `python3 scripts/check-writing-pages.py` 并按文档抽样验收。
