OpenAI Agents API

· 工具搜索 — 按需加载，省token保缓存
· 子Agent并行 — 复杂任务拆开同时跑
· MCP原生支持

Claude Agent SDK

· 内建权限系统 — permission_mode
· Hooks机制 — 循环关键节点插入审计
· Session持久化JSONL — resume/fork
· 从Claude Code演化而来
