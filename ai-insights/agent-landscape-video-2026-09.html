01 · 模型厂商原生

四家厂商 四条路

🅾️OpenAI Agents API — Codex 引擎开放为托管服务，自动上下文压缩、工具搜索、子Agent并行
🅰️Claude Agent SDK — 本地进程运行，内建权限系统和Hooks，开发者掌控全部细节
🟢Google ADK — A2A协议原生支持，多语言，v2加入图工作流
🐋DeepSeek Harness — MIT开源，一切皆插件，Cordis微内核架构，完全可自托管
02 · 云平台与社区

基础设施层 + 开源生态

🔶Strands Agents — AWS开源，3行Python起步，多模型不锁定，可直接部署到AgentCore
☁️AgentCore Harness — AWS全托管，配置即Agent，microVM隔离，版本化灰度发布
🔗LangGraph — 图架构，显式状态转移，checkpoint恢复，审计性最强
👥CrewAI — 角色驱动多Agent，按职能分工，从零到可用最快

04 · 五个趋势

正在发生的变化

1自建变服务 — Agent基础设施从代码变成平台
2SDK+托管双轨 — 本地开发，云端运行成为标配
3协议层收敛 — MCP和A2A正在成为跨框架通用语言
4工具生态关键 — 模型趋同后，工具连接成为差异点
5治理成准入 — 过程审计和权限边界变成必选项
05 · 向上指引

技术人的三个阶段

①理解Agent循环 — 从Strands或CrewAI起步，跑通一个真实任务
②Demo到生产 — 学Session管理、权限系统、可观测性
③建立壁垒 — 工具设计 + 验证闭环 + 过程审计，框架换了经验还在
