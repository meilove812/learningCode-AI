🔭 它是什么？

一句话

DeepSeek Harness (dsh) 是让 AI 模型变成能读写文件、执行代码、使用工具、自主规划的 Agent 的开源运行框架。

MIT
开源协议
3种
使用方式
∞
可接模型
100%
插件化

不是模型，是"Agent 操作系统"：模型适配器、工具注册、会话管理、Agent 循环全部是可替换插件。

💡 核心理念

🎯 Everything is a Plugin

没有特权核心，没有硬编码。你不是在用一个框架的"扩展接口"，而是框架本身就是插件的组合。

⚡ Cordis 框架

基于"时空可组合性"学术论文的插件范式。五大理念：
① 插件=Service ② Context=仓库 ③ inject=依赖 ④ Event=通信 ⑤ Effect=可逆

🌐 模型无关

DeepSeek V4 · Claude · GPT · Gemini · Ollama 本地 — 任何兼容端点一键接入。

🛠️ 三种入口

Web UI · CLI · Python SDK — 从个人到企业全覆盖。

🏗️ 三层架构

Profile→ Bundle→ Plugin

📦 Profile（组合配置）

命名的插件组合，存储在 Home 目录。web / headless 两个模板。

📚 Bundle（功能层）

dsh-base：模型适配+工具+持久化+沙箱+凭证
dsh-web-app：浏览器应用
dsh-headless：无服务器一次性运行

🧩 Plugin（具体能力）

每个功能=一个插件。加载顺序由 inject 依赖声明决定，不用手动排序。

🧩 6大核心包

📋 session

Append-only 事件日志，一切真相源

🧠 agent

Agent 接口+注册表+生命周期事件

🔄 agent-loop

Turn/Step 循环驱动器

🛠️ tools

作用域工具注册+执行管线

📝 system-prompt

Prompt section 自动组装

🤖 llm

统一多协议模型适配器

能力接缝：每个能力 = 接口声明 + 实现 + 消费者。换一个 Provider ⇒ 整个执行环境跟着切换。

🔄 请求流转

Step = 1次模型请求 + 工具调用
Turn = 0~N 个 Step（从输入到完成）

输入→turn/start→pre-step
组装Prompt→LLM流式→assistant/msg
tool/call→execute→tool/result
step/end→还有工具?→turn/end

关键设计：模型看到的一切都从 Session Log 重建。Waterfall 事件让插件能拦截/改写/短路任何步骤。
