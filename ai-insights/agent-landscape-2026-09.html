五个趋势

① 自建 → 服务

Agent harness 正在从开发者代码里抽出来变成平台能力，跟数据库从自建变RDS一条路

② SDK + 托管 = 双轨标配

Strands+AgentCore、Claude SDK+Managed、OpenAI SDK+API——本地开发，云端运行

③ 协议层正在收敛

MCP（工具连接）和 A2A（Agent通信）正在成为跨框架的通用语言，选框架的锁定在降低

④ 工具生态 > 模型能力

模型能力趋同后，谁的工具连接更丰富、企业系统集成更顺，谁更有优势

⑤ 安全治理从可选变必选

AgentCore Gateway、OpenAI 过程审计——权限边界和行为审计正在变成准入门槛

技术人向上指引

🟢 刚接触

从 Strands（3行Python）或 CrewAI（角色分工最直观）起步。核心：理解 Agent 循环

🟡 能跑 Demo → 想做生产

三件事：Session 管理（状态存储恢复）、权限系统（能做什么不能做什么）、可观测性（出问题怎么排查）

🔴 建立不可替代性

框架半年一换，不要学框架本身。三项留在人这侧的能力：
① 工具设计 — 把业务流程拆成可调用的工具
② 验证闭环 — 判断产出在业务上可用
③ 过程审计 — 确保中间过程可控
