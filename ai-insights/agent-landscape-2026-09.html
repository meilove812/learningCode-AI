四个趋势

① 自建 → 服务

Agent 运行循环（harness）正在从开发者代码里抽出来，变成平台能力。跟十年前数据库从自建变 RDS 是同一条路。

② SDK + 托管 = 双轨标配

Strands+AgentCore、Claude SDK+Managed Agents、OpenAI SDK+Agents API——全部是「本地开发，云端运行」的双级火箭。

③ 工具生态 > 模型能力

模型能力趋同后，谁的工具连接更丰富、MCP 生态更完整、企业集成更顺，谁赢。

④ 安全治理从可选变必选

AgentCore 把策略放到 Gateway 层，Agent 绕不过。过程审计、权限边界正在从「最佳实践」变成「准入门槛」。

技术人向上指引

🟢 刚接触

从 Strands 或 Claude Agent SDK 起步，理解 Agent 循环：模型调用→工具选择→执行→回传→循环

🟡 能跑 Demo，想做生产

学三件事：Session 管理（状态存储与恢复）、权限系统（能做什么不能做什么）、可观测性（出问题怎么排查）

🔴 建立不可替代性

框架半年一换。留在人这侧的能力：工具设计（业务流程→可调用工具）、验证闭环（产出在业务上可用）、过程审计（中间过程可控）
