📦 分包传输 → 重组还原

一张 2MB 照片不能一次性塞进卫星链路，必须切成小包逐个发送

📸

1. 原始图片（~2MB）

拍摄的天空照片，JPEG 压缩后约 2MB

📷 完整图片 2,048 KB
✂️

2. TCP 分段（~1,460 字节/段）

TCP 按 MSS 切割，2MB ≈ 1,400+ 个数据段，每段加上包头

🚀

3. 逐包通过卫星链路发送

每个包独立经过：Wi-Fi → 机顶天线 → 卫星 → 地面站，可能乱序到达

🧩

4. 接收端重组还原

微信服务器按序号重组所有分段，校验完整性，还原出原始照片

✅ 图片完整还原
📨

5. 推送给朋友

微信服务器通过朋友的 4G/5G/Wi-Fi 推送图片，朋友看到「图片消息」

⏱ 时间线：从按下快门到朋友看到

0 ms

📸 按下快门

手机拍摄照片，JPEG 编码压缩

50 ms

📶 连接机舱 Wi-Fi AP

手机通过 Wi-Fi 将数据发到机载路由器（几毫秒）

100 ms

📡 机顶天线调制上行

数据包转换为 Ku/Ka 波段射频信号，通过相控阵天线发射向卫星

370 ms

🛰️ 信号到达卫星

电磁波以光速飞行 36,000km（~120ms），卫星转发器变频转发

490 ms

📡 地面站接收

卫星下行信号被地面站大口径天线接收，解调还原为 IP 数据包

520 ms

🌐 进入互联网骨干网

数据通过光纤到达微信腾讯云服务器，开始重组图片

2-8 秒

🧩 所有分包传输完成

2MB 照片的 1400+ 个包全部到达并重组（受卫星带宽限制，不是延迟）

2-8 秒

📨 朋友收到照片

微信通过 Push 通知推送，朋友手机显示「图片消息」
