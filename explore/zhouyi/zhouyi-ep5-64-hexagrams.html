六十四卦的诞生
第五期 · 八卦重叠的奥秘
从八到六十四
上一期我们学了八卦，
它们是自然界的8种基本符号。

但8个还不够！
古人想：如果把两个卦叠起来呢？

8 × 8 = 64种组合！

就像8种颜色两两配对，
能配出64种新花样。
重卦的结构
两个三爻卦叠在一起，
就变成了一个六爻卦。

上面三条叫上卦（外卦），
下面三条叫下卦（内卦）。

就像搭积木，
两块积木叠成更高的塔。
上下不同，意义不同
同样是乾和坎两个卦，
谁在上、谁在下，含义完全不同！

乾上坎下 = 天水讼（争论）
天往上走，水往下流，方向相反→起冲突

坎上乾下 = 水天需（等待）
乌云在天上，要下雨了→耐心等
六十四卦怎么取名？
每个卦的名字，
都藏着它的画面和含义：

☰☰ 乾卦 = 天叠天 → 刚健不息
☷☷ 坤卦 = 地叠地 → 厚德载物
☵☳ 屯卦 = 水上雷下 → 草木初生
☶☵ 蒙卦 = 山上水下 → 蒙昧待启

名字本身就是一幅画！
💡 取名小规律
上下卦相同 → 用本卦名（乾、坤、震…）
上下卦不同 → 根据组合画面取新名
比如"火在水上" → 既济（已经渡河）
周文王与六十四卦
周文王被商纣王关进监狱，
一关就是七年。

在暗无天日的牢房里，
他没有放弃，反而静下心来，
把八卦两两重叠，
推演出完整的六十四卦。

最伟大的智慧，
往往诞生于最艰难的时刻。
六十四卦的排列
六十四卦的顺序不是随意的，
它讲述了一个完整的故事：

开头：乾（天）+ 坤（地）
天地初开，万物开始。

结尾：既济（完成）+ 未济（未完）
事情做完了，新的又开始了。

结束就是新的开始，永不停歇。
人生地图
六十四卦涵盖了
人一生中所有可能的处境：

刚开始创业 → 屯卦（艰难起步）
遇到困难 → 坎卦（重重险阻）
获得成功 → 大有卦（收获满满）
需要退让 → 遁卦（适时隐退）
家庭和睦 → 家人卦（齐家之道）

不管你遇到什么，
六十四卦里都有对应的指引。
生活百科全书

📖 64个"章节"
每一章讲一种人生场景

小结
八卦 × 八卦 = 六十四卦

上卦 + 下卦 = 一个完整的六爻卦
上下颠倒，含义完全不同

周文王被囚七年，
推演出这套完整的系统。

六十四卦 = 人生的64种场景
是地图，是百科，是指引。
