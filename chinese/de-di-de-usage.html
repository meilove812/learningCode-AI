的 地 得
三个"de"，用法大不同

它们读音一样，但位置不同、搭配不同、意思不同

← 左滑翻页 · 点下方▶️自动讲解 →
的
白勺「的」· de
形容词/名词 + 的 + 名词
🌸 美丽的花朵
→ 什么样的花朵？美丽的
🎒 红色的书包
→ 什么颜色的书包？红色的
🤲 妈妈的手
→ 谁的手？妈妈的
地
土也「地」· de
副词/形容词 + 地 + 动词
💃 快乐地跳舞
→ 怎样跳舞？快乐地
✍️ 认真地写字
→ 怎样写字？认真地
📢 大声地朗读
→ 怎样朗读？大声地
得
双人「得」· de
动词 + 得 + 补语（结果/程度）
🏃 跑得快
→ 跑的结果怎样？快
✅ 写得好
→ 写的程度怎样？好
😂 笑得肚子疼
→ 笑到什么程度？肚子疼
📝
记住口诀
🌸 名词前面 → 白勺的
💃 动词前面 → 土也地
🏃 动词后面 → 双人得
简单说：
的 → 修饰东西（名词）
地 → 修饰动作（动词）
得 → 补充结果（程度）
🔍 对比一下
😊 高兴的孩子
→ 什么样的孩子？（修饰名词）
😊 高兴地跳
→ 怎样跳？（修饰动词）
😊 跳得高
→ 跳的结果？（补充程度）
看！同样和"高兴/跳"相关
